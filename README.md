# Taller Práctico: Página de Presentación (Estilo Manga / Dragon Ball & Berserk)

¡Hola! Este repositorio contiene la tarea práctica correspondiente a la asignatura **Diseño de Sistemas en Internet** de la Universidad Nacional de Ingeniería (UNI).

## Descripción del Proyecto
Portal web de presentación personal desarrollado con una estética de manga inspirada en Dragon Ball y Berserk, cumpliendo con los estándares de estructura frontend en HTML y CSS pautados en clase.

### Características implementadas:
- Estructura HTML semántica: Encabezado principal, párrafos de presentación, listas de habilidades e intereses, imagen local e integración de enlaces.
- Diseño Visual Temático:
  - Marco exterior personalizado con la figura de Shenlong.
  - Esferas del dragón distribuidas en el fondo con efectos interactivos de brillo al pasar el cursor.
  - Maquetación basada en viñetas y tramas de puntos (*halftone*) estilo cómic japonés.
